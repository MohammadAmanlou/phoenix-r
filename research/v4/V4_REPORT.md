# PHOENIX-R V4: Counterfactual Repair Coordination in Dynamic Information Environments
## Decision and scope
Read the actual V3 report and code. V4 replaces iid repair scenes with a persistent finite evidence bank, private discoveries, a public archive, repeated audience opportunities, selective logs and a closed-world text environment. Focus on an empirical causal question, not a generic new theory of collective search. Two synthetic policies can have identical initial claim, first-round marginal source access and 24 queries yet differ in joint correction. In real studies match initial answer texts and factual correctness distribution, not post-treatment outcomes. No claim that all later per-route success probabilities are matched; feedback and selection can change them. The current model conditions on a seeded false claim; it is not an empirical 95% accuracy experiment.

Candidate distinction: a randomized **joint source assignment policy** in the same human–AI misinformation room, equalized source marginals and budget, separate discovery, evidence verification, relay, recipient recovery and post-outcome audit. Neither generic diversity nor generic social learning is new. Main empirical hypothesis: joint dependence can lower verified recovery even if individual initial task metrics appear comparable, and endogenous visibility can hide this loss. The repeat-measurement counterexample prevents a simplistic “more diversity is always better” conclusion. Direct joint randomized audit and matched information access are essential baselines. This candidate may be reduced by new work or fail empirically.

## 1. Exact dynamic finite-bank model
m roots independently contain decisive evidence with probability p; evidence status is persistent. At each round k queries are assigned. Shared: k agents receive one uniformly selected root; iid: k independent uniform selections; distinct: uniform k-subset; rotate: uniformly permuted roots cycled over time. In all four, each first-round query marginal is uniform and has success p, and cost is kT. All runs start with the same seeded erroneous claim. Before first discovery, schedules are independent of root truth. Let U_t be number of unique roots queried. The probability of no discovery is S_t=E[(1-p)^U_t], by conditioning on the schedule. The distinct transition from u to u+j has probability C(m-u,j) C(u,k-j)/C(m,k). Shared uses k=1; iid is the k-th matrix power of the shared transition; rotate sets u'=min(m,u+k). This is an occupancy identity, not a new general theorem. In the perfect-recognition model rotation attains the best possible coverage and thus discovery probability; independent repeated noisy measurement invalidates this guarantee.

Let d_t=S_(t-1)-S_t. After a discovery, each round gives an independent relay chance b, then after publication an independent audience uptake chance a, including the same round. The exact recovery probability by T is

C_T = sum_{t=1}^T d_t sum_{j=t}^T (1-b)^(j-t) b [1-(1-a)^(T-j+1)].

Proof: condition on first discovery t and first public relay j; adoption by T is the complement of all uptake attempts failing. Archive-first retrieval after publication can change subsequent queries but cannot change the first discovery or publication and, under independent uptake, cannot change this endpoint. This is a deliberately restricted model of carryover, not general RL. Logging is a separate outcome-dependent channel (0.8 if no recovery, 0.4 if recovered). The visibility indicator has no influence on the archive; no claim that real logging is passive.

## 2. Repeat measurement and false discovery
If a root must produce h independent positive measurements before qualifying, sensitivity s and false positive f, then given fixed outcome-independent allocation counts n_j, define B(n,z,h)=P(Binomial(n,z)>=h). With root prevalence p, the chance of any qualifying root is
Q(n)=1-product_j [1-p B(n_j,s,h)-(1-p)B(n_j,f,h)].
Under an all-null true claim, false qualification is F(n)=1-product_j [1-B(n_j,f,h)]. Proof: condition on independent root labels and independent measurement noise, then multiply probabilities that each root fails to qualify. It is not a new multiple-testing theorem. This endpoint is qualification, not proof-grounded correction or downstream uptake. Search all unordered integer allocations with sum n_j=B; under exchangeability any ordering has the same Q,F, so enumeration is an exact deterministic nonadaptive allocation oracle (not an adaptive policy). A single positive hit is unsafe when repeated multiple testing is not controlled; diversified search can be harmful when evidence needs replication. Use root-specific noisy validation, not copied reports as independent measurements.

## 3. Executed tests and results
`dynamic.py` 960,000 synthetic policy-room trajectories, 1,432 analytic/Monte Carlo/order checks (all passed; not independent proofs). Across arms common random numbers induce pairing; each arm has 20,000 simulated rooms per setting. Eight rounds, 3 queries per round, 12 persistent roots. At p=.10, relay=.85, uptake=.65, archive feedback enabled: shared .44520, iid .65815, distinct .66710, rotate .71860 recovered. Paired rotate-shared delta .27340; Monte Carlo 95% normal interval [.26721,.27959]. Exact rates .442411, .653130, .664761, .716081. The interval quantifies simulation uncertainty, not human effect uncertainty. After publication archive-first retrieval can inflate repeated successes without new roots.

`stress.py` 600,000 synthetic trajectories: 5 policies x 3 measurement thresholds x 2 truth conditions x 20k. Noise s=.65, f=.025. Popular policy samples proportional to 1+3 cumulative visits, generating pre-repair feedback. Threshold 1: rotate adoption 79.50% vs shared 67.51%, true-claim false adoption 42.75% across all policies. Threshold 3: rotate 0% (each root receives at most two measurements), shared 22.535%, popular 19.86%; true-claim false adoption shared .075%, rotate 0%. Adoption under a false claim is not necessarily supported by a true root; see verified_root_true column. Parameters are constructed; no empirical tuning. The threshold-3 reversal is an explicit counterexample to generic diversity claims, not evidence that shared search is always preferred.

`frontier.py` 27,372 allocation evaluations across 108 settings. At m=12, B=24, false qualification cap 1%, threshold 1 infeasible; threshold 2 gives Q=.42099987, F=.00927439 for allocation 0, nine 2s and two 3s; threshold 3 yields Q=.31398414, F=.00066295 for allocation seven zeros, one 4 and four 5s. Do not equate terminal qualification with adoption. The cap only holds under stipulated measurement laws; no universal guarantee.

`text_env.py`: 40 fictional registry claims (20 false/20 true), 4 policies, 160 scripted room trajectories. Correct grounded recovery among false cases: shared 16/20, iid 19/20, distinct 20/20, rotate 20/20. False corrections 0/20 per policy, expected with ideal oracle and deterministic reader; no human/LLM experiment. Text traces saved in JSONL. LLM adapter exists but not run, no model weights available. The gate uses synthetic oracle metadata and does not generalize to live news. Equal call count does not guarantee equal tokens/latency; record those in real LLM tests.

## 4. Next empirical gate and supervisor fit
Randomize at isolated room level: same initial claim and exact evidence quality distribution, same displayed text, same per-user chance of each root, equal access budget; shared source assignment vs disjoint/rotated assignment; cross with randomized post-discovery relay support. Include policy with adaptive search, fixed independent queries and strong sequential search/confirmation baselines. Equal marginal assignment is an experimental control, not equal realized success. Predeclare ground truth with fictional or independently fact-checked low-risk claims; record route-level attempts, sources and dependencies, verified discovery, relay, later recipients' belief and actual sharing decisions. Do not condition analysis on successful discovery; use intention to treat and all randomized rooms. Separate a lawful retrospective readout of existing records after endpoint lock from a prospective intervention that changes outcomes.
