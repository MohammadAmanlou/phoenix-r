These sources were checked against indexed abstracts/publisher records, not an exhaustive full-text citation census. The new design isolates timing and joint source allocation at fixed total document coverage and query count, with a second factor for persistence of relayed records. Generic source diversity, communication controls, shared evidence and group reasoning failure are not novel. The current task is intentionally simple; the scripted effect follows from the construction and is NOT evidence that the underlying phenomenon is new. No SOTA or publication-ready claim.

## Controlled design
Each independent fictional registry case has four lineages with three documents each (original and mirrors); two accredited lineages agree on the actual value; two unofficial lineages repeat the displayed claim. Paired truth conditions are balanced with deterministic pseudorandom order; opaque case IDs avoid exposing the index/label. Distinct splits use separated seeds, maximum 10,000 cases per split. All four policies see the same 12 documents exactly once privately, 3 agents each round for 4 rounds. Clustered assigns one lineage per round; dispersed assigns one document from each of three lineages, excluding each lineage once. Random permutations exchange document/lineage positions in the generator. Under ideal uniform permutations each slot has equal document marginal across the two assignment schedules; realized outcomes and time of exposure need not match. Factor 2: snapshot relay (only current submitted documents) versus persistent relay (all previously submitted documents). Agents see their own record and previous public reader verdict; reader sees relayed documents and previous verdict. No direct memory of private documents across calls. No truth gate; only syntax and visible ID validation. Agent and reader prompts do not contain generator gold labels. Public source accreditation is a fictional task rule. Reader must cite two distinct accredited lineages reporting an agreeing value to count as grounded refutation. Report schema-valid raw refutation, incorrect/ungrounded refutation, invalid outputs, first grounded round and verified recovery. Invalid outputs do not magically become successes. A true-claim raw refutation is counted even when it is semantically unsupported. Raw here means schema-valid; malformed refutations are included in invalid outputs, not silently counted as valid. This is a fixed bank (no actual creation of new evidence), not the full co-evolving human system. Prior reader verdict provides minimal feedback, not continual learning.

Each room uses 12 agent + 4 reader requests = 16. Arms ordered by cyclic counterbalancing across cases; each case tested in all four arms in isolated calls. Equal calls are NOT equal token/time budget: persistent contexts can be longer. Log prompt/completion tokens when endpoint returns them, latency, raw outputs, citations and visible IDs. Hold decoding settings fixed (temperature 0, 160 max output tokens); determinism not guaranteed. Manifest stores model tag, operator-provided revision, split, case count, endpoint, Node version and source hash. Never store API keys. Completed rooms persist in JSONL; transport failure stops run, error logged and incomplete room retried from start when resumed. Failed/retried calls are outside completed-room call totals; count transport costs separately when reporting. Do not mix runs or models.

## Executed controls
Actual functions from core.mjs executed in JS sandbox: 2,145 assertions passed, 600 unique IDs across 3 splits with exactly 300 false claims, 160 scripted rooms / 2,560 calls. Tests include same coverage, unique docs, clustered/dispersed structure, truth, malformed output, wrong-reader refutations not suppressed, exact binomial upper limit. See scripted_checks.json. Among 20 false claims/arm: clustered+snapshot 0/20 grounded recovery; clustered+persistent 20/20 (mean first grounded round 3.05); dispersed+snapshot 20/20 (2.05); dispersed+persistent 20/20 (1.75). No false corrections among 20 true claims per arm for scripted oracle, as expected. With n=20, zero errors has one-sided 95% Clopper-Pearson upper bound 13.91% under iid sampling; scripted tasks are deterministic fixtures, so this is a calculation check, not a population confidence statement. Degenerate normal paired intervals from deterministic controls do not establish population generalization. These results intentionally validate the design (the clustered snapshot cannot present two independent lineages simultaneously), not a competitive LLM result.
Mock transport/file adapters executed runner control flow: 5 checks passed, 135 simulated HTTP requests including 7 up to deliberate 503, 128 requests in 8 completed rooms, resume made zero additional calls, manifest mismatch rejected. This is not a real Node filesystem/HTTP integration test. See runner_mock_checks.json.

## Real-model run protocol (pending)
Install Node.js 22+ and Ollama on a machine with enough RAM and storage. The endpoint follows [Ollama OpenAI compatibility](https://docs.ollama.com/api/openai-compatibility). [Qwen3:4b-instruct](https://ollama.com/library/qwen3:4b-instruct) is a small quantized 2.5GB starting model, not a SOTA benchmark claim. Pin exact digest via ollama list, record machine, Ollama version and model metadata; replace YOUR_DIGEST below. On repo root:
```bash
node research/v6/run.mjs --selftest
ollama pull qwen3:4b-instruct
ollama list
node research/v6/run.mjs --backend llm --model qwen3:4b-instruct --revision YOUR_DIGEST --split smoke --cases 2 --out local_runs/v6-qwen3-smoke
```
Ollama must be running (launch its application or ollama serve if not already running). No extra Node packages needed. Default endpoint localhost:11434/v1/chat/completions. 128 completed calls, 8 rooms. Do not report accuracy from smoke as research evidence. If invalid outputs are frequent, adjust prompts/decoding on smoke only, freeze source hash then restart fresh directories. Independent calibration (e.g. 120 balanced cases, 7,680 calls) and independent test (e.g. 120 balanced cases, same calls) are planned, not mandatory first run. Each true-claim arm has 60 cases at n=120. If zero errors, the iid room-level upper 95% bound is about 4.87%; not a guarantee of V5's full-history conditional null bound. Do not use a room-average rate as conditional u. For population inference randomize/sample rooms under prespecified target distribution, account for model stochasticity, paired comparisons and multiplicity. Choose a study size by power analysis, not synthetic effect sizes. Preserve raw outputs and manifests; compare models with same benchmark version and inference config, log actual token and latency budgets. External baselines (HiddenBench/TIDE/Consilience) must be implemented or obtained from their actual releases and run on their own tasks plus harmonized settings; do not imply replication or superiority yet. Add full-information diagnostic and challenging noisy/conflicting evidence fixtures, per-stage prospective access and post-outcome readouts before stronger causal claims. Human participants require separate ethics-approved protocol; LLM trials cannot substitute for them.
